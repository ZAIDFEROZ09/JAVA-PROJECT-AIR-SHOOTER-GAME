🚀 Air Space Shooter Game – Java OOP Project

Air Space Shooter Game is a 2D Java-based game developed using Swing GUI and Object-Oriented Programming (OOP) concepts. The project focuses on creating an interactive shooting game where the player controls a fighter plane, destroys enemies, avoids attacks, and survives through different levels.

The game includes features such as player movement, bullet shooting, enemy spawning, collision detection, score tracking, boss fights, power-ups, sound effects, and background music. Java Swing and AWT are used to build the graphical user interface and manage game visuals.
